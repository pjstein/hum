# docs

The source of truth. Specs are normative; `design.md` explains intent. When
they disagree, the spec wins and you flag it.

| Path | What | Owner |
| --- | --- | --- |
| `design.md` | What we're building and why | project owner |
| `specs/` | Normative specs, one per wave 0 workstream (see each prompt's `Owns` line) | W0-01 to W0-09 |
| `specs/reviews/` | Adversarial spec reviews | W0-10 and the `spec-reviewer` agent |
| `DECISIONS.md`, `decisions/` | Decision log and ADRs | everyone adds; owner accepts |
| `ux/` | Screens, flows and the visual language | project owner; W2-05 checks conformance |
| `research/dp-polis/` | The DP math and its oracle | reused by W0-08 and W0-09 |
| `SOURCES.md` | Living versions and standards | project owner |
| `ops/` | Keys, deployment, local network | W1-13 platform |
| `reports/`, `audit/` | Wave 2 reports and the audit package | W2-01 to W2-06 |
